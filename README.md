# Pokémon Chess

Pokémon-themed chess with two-player mode, four bots, random team selection, two-capture evolutions, and normal/shiny pixel-art sprites.

This repository uses the Tkinter version of the game. Download it via **Code → Download ZIP** on GitHub.

To start: run `python3 play.py` from the extracted folder. The first launch reconstructs `pokemon_chess.py` from the included source archive and starts it. Future launches work the same way. No Pygame installation is required; Python with Tkinter support is needed.

Pokémon and chess-piece PNGs are downloaded on first launch, subject to source availability. The ZIP does not bundle those third-party images.
